OBJECT FILE · 1997–1999

AIM away message

Choose a lyric carefully. Your buddy list is going to read it.

The object’s story

An away message lets an absent person leave a small piece of writing for friends. A buddy list gives the message context: familiar handles, visible status and the expectation that somebody might become available again.

Make the absence sound like you

Edit the away message and use its preview button to change the invented buddy-list display. The text remains in this local demonstration, with no messaging account or network connection. This is an original AIM-style recreation. Its useful trick is social rather than technical: unavailability can still have a voice, a joke or a promise to return.
