THE DECADE, DAY BY DAY

1995

Click Start. Put the disc in.

A new Start button anchored the PC, PlayStation reached North America, and AuctionWeb opened for business. Alanis supplied the car-stereo argument. Jordan returned to the Bulls; Mandela wore a Springbok jersey at the Rugby World Cup.

the future gets a start point · 1995

Windows 95 Start button

About this object

Want to open a program? Start here. Want to shut down? Start here too.

Windows 95’s Start control gathers routes to programs and system functions at the edge of the desktop. It gives a newly started computer an obvious next action. The reference image is specifically from prerelease build 4.00.337, so it should not be mistaken for proof that every retail installation looked identical.

OS: Microsoft Corporation Dateien: BetaWiki-Beitragende ↗ · Public domain

AOL promotional CD

About this object

Bright trial discs promised free hours and a setup wizard while quietly taking over the family phone line.

An AOL promotional disc carries service software and a trial offer into the house. Running the installer is only the beginning: an account, a suitable access number and a working modem connection still stand between the disc and an online session.

the console grows up · 1994–1999

Original PlayStation hardware

About this object

Put the disc in. Keep the memory card somewhere you can find it.

Sony’s original PlayStation separates three jobs across the front and lid: the disc contains software, the controller supplies input and a memory card holds compatible saved data. Two controller ports support local play when the game offers it.
