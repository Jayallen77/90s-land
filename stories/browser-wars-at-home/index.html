The browser wars reached the family desktop

Navigator and Internet Explorer competed over more than a window: they helped decide how a new web looked and who could build for it.

One address, several experiences

A web address promised a common destination. The window used to open it could still change what happened there. A page might rely on a feature one browser handled differently, or tell visitors which software its author preferred. For a household that had only recently learned to dial in, the browser was both a simple doorway and another source of uncertainty.

The earlier Mosaic object in this archive makes a useful starting point. The web did not begin with the familiar modern arrangement of a handful of nearly invisible browsers. Software that made pages approachable helped enlarge the audience for them. The browser’s controls, installation process and treatment of images were part of how the web became usable.

The window became a competitive product

The Computer History Museum describes the mid-decade contest between Netscape and Microsoft as a browser war. Netscape grew from the people and momentum around Mosaic; Microsoft brought its own browser into a world already dominated by Windows on many household PCs. The two companies were competing for the place through which a person would enter the web.

It was a particularly consequential place to occupy. A browser stands between a user and everyone publishing a page. Its defaults can become habits. Its supported features can become targets for authors. Its installation route can make one program convenient before a newcomer has developed a reason to choose another.

What a page builder had to notice

A handmade page looks liberating because anyone can place words, images and links in public. It also involves choices about how those pieces will behave. As browsers developed, authors could be tempted by an effect that looked impressive in one window but less convincing elsewhere. An open publishing medium could acquire small, practical divisions at the point of use.

That tension matters more than a simple list of browser versions. A tool can make the web more expressive while making it harder to share the same experience with everyone. The attraction of a new feature and the frustration of an incompatible page are two views of the same change.

The household version of a corporate fight

Most people did not approach the desktop as a standards committee. They wanted a page to load, an image to appear or a message to go through. A browser might be the one already installed, the one supplied by an access provider or the one a more confident friend recommended. Convenience could settle a choice that looked ideological in a technology magazine.

The shared PC made those choices social. Installing a new program changed the machine other people used. A favorite icon might move; a familiar sequence might stop working; a second browser might remain on the desktop because no one wanted to remove the first. The corporate contest reached home as a set of small alterations to a common tool.

Keep the public idea in view

The first website object and CERN’s licensing history give this story its wider frame. The web’s power came from a shared system of addresses and links, not from requiring every person to own one company’s complete environment. The browser wars tested how that common idea would survive competing implementations.

Compare the early browser with the Windows desktop, then enter the handmade homepage collection. A browser window was a commercial product, a household habit and a publishing platform at once. That combination explains why an apparently ordinary piece of software could become a defining struggle of the decade.
