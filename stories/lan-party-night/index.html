A LAN party started before the first match

Carry the monitor, untangle the cables, and find out whose network settings are wrong.

Before the match, move the furniture

A LAN party could begin with the least glamorous part of gaming: carrying a computer. A tower, a CRT monitor, a keyboard, a mouse, and their cables were a substantial commitment to an evening. The machine that normally stayed beneath a desk had to travel, and the destination needed enough tables, electrical outlets, and room for everyone to sit.

LAN meant local area network. Instead of depending on a distant server, the participating computers communicated across the network assembled in the room. That simple description leaves out the memorable work: identifying which cable belonged to which machine, making the software agree, and helping the last person reach the same game as everybody else.

Build a small Quake-era network

The opening diagram shows one illustrative 10BASE-T Ethernet arrangement: each computer connects to a hub with its own cable. The hub gathers the local connections; it does not run the game server for you. One participating computer can also host the session. A dial-up modem is unnecessary for traffic that stays on this local network.

Other 1990s networks used coaxial cable, different adapters or protocols. This star-shaped example should not be mistaken for the only authentic LAN-party layout.

The game has to agree with the network

For Quake-era TCP/IP play, matching game versions, reachable local addresses and the host’s session settings matter. A working electrical connection is only the start. Fire up the multiplayer browser or connect using the game’s own instructions, then test with two machines before inviting the whole room.

Doom’s original multiplayer history includes IPX networking, a different setup from simply following Quake’s TCP/IP instructions. The developer source helps explain why “old PC multiplayer” is not one universal procedure. Shared game files, adapters and configuration had to line up before the shouting could begin.

Check the picture, controls and sound at each chair. Start one short session. Let another machine join. Only then commit to rearranging the evening around a long match. This is a practical reconstruction, not a remembered party or an assertion that every player used the same equipment.

Once it works, the network’s best feature is visible without a diagram: the person responsible for that last shot is sitting somewhere you can point to.
