## The code needs the screen, too

“Try it again” was terrible technical support. A friend could give you the right sequence and still leave out the game version, the menu, or the moment to enter it. The useful scrap of paper needed three things: **which game, what to type, and what should happen**. Without those, a real cheat and a playground rumor looked much the same.

Start with Doom. Its cheats are especially satisfying to inspect because id Software later published the code that recognizes them. These instructions concern the original PC games and their classic behavior. A console conversion or modern rerelease can use a different input system.

## Three experiments in the original Doom

Type these letters during ordinary single-player play; you do not open a command console or press Enter. The original handler excludes network games and Nightmare difficulty. Save your normal game first if you want to return to its unaltered challenge.

| Game and version | Input | Visible result |
| --- | --- | --- |
| Doom, original PC game | `IDDQD` | Toggles god mode. Ordinary enemy damage stops being the main problem. |
| Doom, original PC game | `IDKFA` | Gives weapons, ammunition, armor and keys. A locked door becomes a different proposition. |
| Doom, original PC game | `IDSPISPOPD` | Toggles walking through walls. |
| Doom II, original PC game | `IDCLIP` | The sequel’s shorter no-clipping command. |

The last two entries are a useful little trap for half-remembered instructions: the same effect has a different command in the two games. And invulnerability does not teach you a map. You can survive an encounter and remain gloriously lost.

[The developer’s cheat handler](https://github.com/id-Software/DOOM/blob/master/linuxdoom-1.10/st_stuff.c) records both the strings and the changes they trigger. That is firmer evidence than a list that quietly combines PC, PlayStation and later ports.

## A controller sequence is a different kind of knowledge

The Konami command began before this decade, in the Famicom version of Gradius. Its directions became famous enough to circulate independently of the game. That is exactly why a cheat guide needs context: recognizing a pattern does not establish what it does in every title.

On a keyboard, the instruction is a word. On a controller, it becomes a little performance. One person reads directions; another taps the pad; both watch for confirmation. A failed attempt can mean the sequence is wrong, the timing is wrong, or the promised feature never existed. The television supplies the verdict.

## GameShark was doing another job

A built-in cheat asks the game to recognize an instruction its programmers included. A [GameShark cartridge or disc](/archive/objects/game-shark/) changes the arrangement. Its codes target values in compatible software, so the platform, game and revision matter. An address useful for one release is not a universal “infinite lives” button.

A password is different again: it may be the game’s intended way to resume progress. An unlockable may reward normal play. Calling all three “cheats” obscures the interesting part—who designed the shortcut, and what it lets the player change.

The best secret was demonstrable. Not “my cousin says it works,” but a familiar game doing something strange in front of the room. Keep the controller, the paper and the exact version together. That is a proper exhibit.
